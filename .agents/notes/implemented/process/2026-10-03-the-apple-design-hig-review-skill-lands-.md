# Agent Note: the apple-design HIG review skill lands as an agent skill

Status: implemented

## Problem

UI work in this repo (the Web Clients, the composer surfaces) had no
grounded design-review instrument: reviews leaned on general taste, and a
recent four-skill bake-off against `web-client-whale` showed that
HIG-grounded reviewers catch real, verifiable defects (contrast math,
hit-target sizes, a dead animation override) that ungrounded review misses.
The skills live outside the repo, so nothing pins which instrument reviews
run against, and every session re-discovers or re-picks one.

## Decision

`apple-design-skill` (upstream dickwu/apple-design-skill @ `904b0ee`,
pulled 2026-10-03) lands as a pinned vendored agent skill at
`.agents/skills/apple-design/` — SKILL.md (the review workflow), 123 HIG
reference pages regenerated by the upstream script from
developer.apple.com, the regeneration script itself, and ORIGIN.md
recording the pin (sha, date, license posture: Apple owns the guideline
text; upstream ships no OSS license, so the tree is vendor evidence, not
redistributable product code). `tools/check-size.py` gains
`VENDORED_AGENT_SKILL_DIRS` exempting the pinned tree from the size
contract — upstream files are verbatim, same rationale as the existing
vendor/staged-closure exemptions. The bake-off verdict (same day) ranked it
first of four candidates: procedure clarity 5/5, routing table accurate,
~184KB context cost per review, findings evidence-backed.

## Alternatives considered

- justinwetch/HIGAgentSkills (502⭐) — excellent condensed corpus but ships
  no license at all, carries duplicate reference corpora, and its router
  has a blind spot for webview-rendered targets (the review target class
  here). Loses on licensing plus fit.
- ehmo/platform-design-skills web skill (603⭐) — solid WCAG checklist but
  ships real rule defects (invalid `prefers-contrast: forced`, wrong WCAG
  2.2 clause numbering) and no Apple aesthetic lens. Kept as an external
  specialty tool, not vendored.
- axiaoge2/Apple-Hig-Designer (154⭐) — a creation skill, not a reviewer;
  internally contradictory token scales. Revisit if a green-field
  scaffolding skill is wanted.
- Referencing the skills by clone path outside the repo — rejected: the
  pin lives outside version control, so reviews would not be reproducible
  from a fresh checkout.

## Consequences

Design reviews can now ground findings in a pinned HIG corpus with a
stable citation path. The references go stale as Apple edits its pages;
refresh by re-pulling upstream and bumping ORIGIN.md. The 1.5MB vendored
text is a deliberate third-party redistribution consistent with the
existing vendor discipline (attribution recorded at ORIGIN.md).
